# Security policy

Overseer is a local filesystem tool with approval-gated mutation. Do not publish a suspected vulnerability with exploit details before maintainers have had a reasonable opportunity to assess it.

No public security contact has been designated yet. Until repository hosting and a private disclosure channel are configured, report a suspected issue directly to the repository owner through the same private channel used to obtain this source. Do not invent or infer a contact address.

Include the affected version, operating system, filesystem, minimal reproduction, expected safety invariant, and observed result. Remove secrets and client data from all reports.
